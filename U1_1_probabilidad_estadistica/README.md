# Probabilidad y Estadística

Repositorio para entregas de prácticas - materia big data

## Estructura

- `data/raw/` — datos originales (CSV, metadata y README de cada dataset).
- `notebooks/` — notebooks con los análisis.
- `requirements.txt` — dependencias del proyecto.

## Cómo ejecutar

1. Crear y activar el entorno virtual.
2. Instalar dependencias: `pip install -r requirements.txt`
3. Abrir `notebooks/01_evolucion_poblacional.ipynb` y ejecutar todas las celdas.
